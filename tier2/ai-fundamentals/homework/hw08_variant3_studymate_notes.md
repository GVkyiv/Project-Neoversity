Варіант 3. Освітній асистент StudyMate
Продуктовий контекст

Освітній асистент — це помічник для студентів та школярів, який допомагає у навчанні точних наук. Бот може знаходити формули з математики, фізики та хімії, конвертувати фізичні одиниці, надавати інформацію про хімічні елементи та допомагати планувати підготовку до іспитів.

Для кого: для учнів і студентів, яким потрібно швидко знайти формулу, розібратися з поняттям або спланувати підготовку до іспиту — без необхідності гортати підручники чи шукати в різних джерелах.

Ключова особливість цього варіанта: бот не просто видає відповідь, а пояснює. Якість пояснення тут важливіша за складність інструментів. Це хороший приклад AI-функції, де UX і поведінка моделі визначають цінність продукту більше, ніж технічні інтеграції.

PM-фокус перед початком. Подумай: чим цей бот відрізняється від пошуку формули в Google? У чому саме цінність діалогової взаємодії? Де бот може нашкодити, якщо відповість впевнено, але неточно?


Що потрібно зробити

1. Запустити базову версію чатбота з практичної роботи.

2. Адаптувати її під освітній сценарій: замінити SYSTEM_PROMPT, реалізувати щонайменше 2 інструменти з переліку нижче, зберегти архітектуру ChatOpenAI + @tool + create_agent + список messages.

3. Провести тестування через серію діалогових прикладів.

4. Додати продуктові коментарі в ноутбуку — після кожного ключового рішення (не в кінці як окреме есе, а по ходу коду).

5. Заповнити продуктову таблицю та таблицю тестування.



Обов'язкові технічні вимоги

Компонент	Вимога
Модель	ChatOpenAI із явним зазначенням моделі, temperature та max_tokens
Інструменти	Щонайменше 2 tools, реалізовані через декоратор @tool
Схема кожного @tool	Типізовані параметри, docstring із поясненням коли використовувати tool, базова обробка помилок
Агент	create_agent(model=..., tools=..., system_prompt=...) — як у практичній роботі
Контекст	Список messages, який передається у agent.invoke({"messages": messages}) на кожному кроці
Тестування	Функція автоматичного тестування (аналог run_automatic_tests())
База формул	Щонайменше 2 предмети, у кожному — мінімум 3 формули
База елементів	Щонайменше 8 елементів у PERIODIC_TABLE (якщо реалізовано periodic_table)


Важливо. Архітектуру спрощувати не можна. Можна спрощувати логіку всередині tools (наприклад, фіксована база замість реального API), але структура системи має залишатися повною.


Інструменти для реалізації

Обери щонайменше 2 з наведеного переліку. Третій — за бажанням.



formula_lookup

Пошук формул за назвою або темою. Повертає формулу, пояснення кожної змінної та приклад застосування. Це основний інструмент бота — саме він демонструє ключову цінність: не просто відповідь, а пояснення.



unit_converter_physics

Конвертер фізичних одиниць: швидкість, температура, енергія, тиск. На відміну від кулінарного конвертера (варіант 1), тут конвертація визначається формулами, а не просто коефіцієнтами — наприклад, Цельсій → Фаренгейт.

Технічна примітка. Конвертації, що містять lambda-функції (PHYSICS_CONVERSIONS), добре працюють для арифметичних операцій, але можуть спричинити проблеми при серіалізації. Якщо виникають помилки — замість lambda використовуй звичайні def-функції або умовні конструкції всередині tool.


periodic_table

Інформація про хімічні елементи: атомна маса, електронна конфігурація, властивості, застосування. Приймає символ елемента або його назву українською.



study_planner

Розрахунок плану підготовки до іспиту: скільки тем на день, чи вистачає часу, розподіл за днями.

Технічна примітка. study_planner у оригіналі має чотири окремі параметри (topics_count: int, days_available: int, hours_per_day: float, difficulty: str). Якщо агент некоректно передає параметри — спрости до одного query: str і парси всередині функції, як показано в шаблоні нижче.

# Конвертації фізичних одиниць — без lambda для надійності
def convert_physics(value: float, from_unit: str, to_unit: str) -> float:
    """Виконує конвертацію фізичної величини за відомою парою одиниць."""
    key = (from_unit.strip(), to_unit.strip())
    conversions = {
        ("км/год", "м/с"):   value / 3.6,
        ("м/с", "км/год"):   value * 3.6,
        ("миль/год", "км/год"): value * 1.60934,
        ("C", "F"):          value * 9 / 5 + 32,
        ("F", "C"):          (value - 32) * 5 / 9,
        ("C", "K"):          value + 273.15,
        ("K", "C"):          value - 273.15,
        ("Дж", "кал"):       value / 4.184,
        ("кал", "Дж"):       value * 4.184,
        ("кВт·год", "Дж"):   value * 3_600_000,
        ("атм", "Па"):       value * 101_325,
        ("Па", "атм"):       value / 101_325,
        ("бар", "Па"):       value * 100_000,
    }
    if key not in conversions:
        return None
    return conversions[key]

from langchain_core.tools import tool
import re

@tool
def formula_lookup(query: str) -> str:
    """
    Шукає математичні, фізичні або хімічні формули за назвою або темою.

    Використовуй цей інструмент, коли учень або студент:
    - питає формулу з математики, фізики чи хімії;
    - хоче пригадати, як щось обчислити;
    - просить пояснити формулу або її змінні.

    Приклади запитів:
    - "яка формула кінетичної енергії"
    - "теорема піфагора"
    - "формула концентрації розчину"
    """
    if not query.strip():
        return "Вкажи назву формули або тему. Наприклад: 'кінетична енергія' або 'теорема піфагора'."

    query_lower = query.lower()

    for subject, formulas in FORMULAS_DB.items():
        for name, data in formulas.items():
            if query_lower in name.lower() or name.lower() in query_lower:
                result = [f"{name.upper()} ({subject})\\n"]
                result.append(f"Формула: {data['формула']}\\n")

                result.append("Змінні:")
                for var, meaning in data.get("змінні", {}).items():
                    result.append(f"  {var} — {meaning}")

                if "приклад" in data:
                    result.append(f"\\nПриклад: {data['приклад']}")

                if "примітка" in data:
                    result.append(f"\\nПримітка: {data['примітка']}")

                if "альтернатива" in data:
                    result.append(f"\\nАльтернативна форма: {data['альтернатива']}")

                return "\\n".join(result)

    # Якщо точного збігу немає — шукаємо часткові збіги
    partial_results = []
    for subject, formulas in FORMULAS_DB.items():
        for name in formulas:
            if any(word in name.lower() for word in query_lower.split() if len(word) > 3):
                partial_results.append(f"  {name} ({subject})")

    if partial_results:
        return (
            f"Точної формули за запитом '{query}' не знайдено.\\n"
            f"Можливо, ти мав на увазі:\\n" + "\\n".join(partial_results)
        )

    return (
        f"Формулу '{query}' не знайдено в базі.\\n"
        "Спробуй уточнити запит або вказати предмет: математика, фізика, хімія."
    )

@tool
def unit_converter_physics(query: str) -> str:
    """
    Конвертує фізичні одиниці вимірювання.

    Використовуй цей інструмент, коли потрібно перевести:
    - швидкість: км/год ↔ м/с, миль/год → км/год
    - температуру: Цельсій ↔ Фаренгейт ↔ Кельвін
    - енергію: Джоулі ↔ калорії, кВт·год → Дж
    - тиск: атм ↔ Па, бар → Па

    Приклади запитів:
    - "переведи 100 км/год у м/с"
    - "скільки Фаренгейтів у 37 градусах Цельсія"
    - "конвертуй 5 атм у Па"
    """
    if not query.strip():
        return "Вкажи значення та одиниці для конвертації. Наприклад: '100 км/год у м/с'."

    query_lower = query.lower()

    # Витягуємо числове значення
    numbers = re.findall(r"-?\\d+(?:[.,]\\d+)?", query)
    if not numbers:
        return "Не вдалося знайти числове значення в запиті. Вкажи число, наприклад: '100 км/год у м/с'."

    value = float(numbers[0].replace(",", "."))

    # Словник розпізнавання одиниць з різними варіантами написання
    unit_aliases = {
        "км/год": ["км/год", "км/г", "кілометрів на годину", "kmh", "km/h"],
        "м/с":    ["м/с", "метрів на секунду", "m/s"],
        "миль/год": ["миль/год", "mph", "миль на годину"],
        "C":      ["градус цельсія", "цельсій", "°c", "celsius", " c "],
        "F":      ["фаренгейт", "°f", "fahrenheit", " f "],
        "K":      ["кельвін", " k ", "kelvin"],
        "Дж":     ["джоуль", "дж", "joule", " j "],
        "кал":    ["калорія", "кал", "cal"],
        "кВт·год": ["квт·год", "кіловат-година", "kwh"],
        "атм":    ["атмосфера", "атм", "atm"],
        "Па":     ["паскаль", "па", "pa", "pascal"],
        "бар":    ["бар", "bar"],
    }

    def detect_unit(text: str) -> str:
        for canonical, aliases in unit_aliases.items():
            if any(alias in text for alias in aliases):
                return canonical
        return None

    from_unit = detect_unit(query_lower)

    # Для визначення цільової одиниці шукаємо після слів "у", "в", "до"
    target_part = re.split(r"\\s+[уводвдо]+\\s+", query_lower)
    to_unit = detect_unit(target_part[-1]) if len(target_part) > 1 else None

    if not from_unit or not to_unit:
        available = "км/год↔м/с, C↔F↔K, Дж↔кал, атм↔Па"
        return (
            f"Не вдалося розпізнати одиниці в запиті '{query}'.\\n"
            f"Доступні конвертації: {available}.\\n"
            "Спробуй: '100 км/год у м/с'."
        )

    if from_unit == to_unit:
        return f"{value} {from_unit} — це вже і є {value} {to_unit}."

    result = convert_physics(value, from_unit, to_unit)

    if result is None:
        return (
            f"Конвертацію з '{from_unit}' у '{to_unit}' не підтримується.\\n"
            "Перевір правильність написання одиниць."
        )

    return f"{value} {from_unit} = {result:.4g} {to_unit}"

@tool

    Повертає інформацію про хімічний елемент з таблиці Менделєєва.

    Використовуй цей інструмент, коли учень або студент:
    - питає про конкретний хімічний елемент;
    - хоче знати атомну масу, електронну конфігурацію або властивості;
    - шукає інформацію за символом (Fe, Au) або назвою (залізо, золото).

    Приклади запитів:
    - "розкажи про залізо"
    - "що таке елемент Fe"
    - "властивості золота"
    """
    if not query.strip():
        return "Вкажи символ або назву елемента. Наприклад: 'Fe' або 'залізо'."

    query_lower = query.lower().strip()

    # Шукаємо за символом (регістронезалежно)
    for symbol, data in PERIODIC_TABLE.items():
        if query_lower == symbol.lower():
            return _format_element(symbol, data)

    # Шукаємо за українською або англійською назвою
    for symbol, data in PERIODIC_TABLE.items():
        if (query_lower in data["name_ua"].lower()
                or data["name_ua"].lower() in query_lower
                or query_lower in data["name_en"].lower()):
            return _format_element(symbol, data)

    available = ", ".join(
        f"{s} ({d['name_ua']})" for s, d in PERIODIC_TABLE.items()
    )
    return (
        f"Елемент '{query}' не знайдено в базі.\\n"
        f"Доступні елементи: {available}."
    )

def _format_element(symbol: str, data: dict) -> str:
    """Форматує інформацію про елемент у зручний вигляд."""
    return (
        f"{data['name_ua']} ({data['name_en']}) — {symbol}\\n\\n"
        f"Атомний номер: {data['number']}\\n"
        f"Атомна маса: {data['mass']} г/моль\\n"
        f"Група: {data['group']}\\n"
        f"Електронна конфігурація: {data['electron_config']}\\n\\n"
        f"Властивості: {data['properties']}\\n"
        f"Застосування: {data['uses']}"
    )

@tool
def study_planner(query: str) -> str:
    """
    Створює план підготовки до іспиту на основі кількості тем, днів і годин на день.

    Використовуй цей інструмент, коли учень або студент:
    - хоче спланувати підготовку до іспиту або заліку;
    - питає, чи вистачить часу вивчити певний обсяг матеріалу;
    - просить розподілити теми по днях.

    Приклади запитів:
    - "допоможи спланувати підготовку: 15 тем, 10 днів, 3 години на день"
    - "чи вистачить 7 днів щоб вивчити 20 тем по 2 години на день"
    """
    if not query.strip():
        return (
            "Вкажи кількість тем, днів та годин на день. "
            "Наприклад: '15 тем, 10 днів, 3 години на день'."
        )

    numbers = re.findall(r"\\d+(?:[.,]\\d+)?", query)
    if len(numbers) < 3:
        return (
            "Не вдалося визначити всі параметри. "
            "Вкажи кількість тем, днів і годин. "
            "Наприклад: '15 тем, 10 днів, 3 години на день'."
        )

    topics_count = int(numbers[0])
    days_available = int(numbers[1])
    hours_per_day = float(numbers[2].replace(",", "."))

    if topics_count <= 0 or days_available <= 0 or hours_per_day <= 0:
        return "Усі значення мають бути більше нуля. Перевір введені дані."

    if hours_per_day > 16:
        return f"Значення {hours_per_day} годин на день виглядає нереалістичним. Перевір дані."

    # Визначаємо складність із тексту запиту
    query_lower = query.lower()
    if "важк" in query_lower:
        difficulty = "важка"
        hours_per_topic = 2.5
    elif "легк" in query_lower:
        difficulty = "легка"
        hours_per_topic = 1.0
    else:
        difficulty = "середня"
        hours_per_topic = 1.5

    total_hours_needed = topics_count * hours_per_topic
    total_hours_available = days_available * hours_per_day
    topics_per_day = topics_count / days_available
    study_sessions = int(hours_per_day * 60 / 25)  # сесії по 25 хв (Помодоро)

    result = [
        f"ПЛАН ПІДГОТОВКИ ДО ІСПИТУ\\n",
        f"Вхідні дані:",
        f"  Тем: {topics_count}",
        f"  Днів: {days_available}",
        f"  Годин на день: {hours_per_day}",
        f"  Складність матеріалу: {difficulty}\\n",
        f"Розрахунок:",
        f"  Потрібно годин (всього): {total_hours_needed:.0f}",
        f"  Доступно годин: {total_hours_available:.0f}",
    ]

    if total_hours_available >= total_hours_needed:
        buffer = total_hours_available - total_hours_needed
        result.append(f"  Часу достатньо! Резерв: {buffer:.0f} год (на повторення)")
    else:
        deficit = total_hours_needed - total_hours_available
        result.append(f"  Увага: дефіцит часу {deficit:.0f} год.")
        result.append("  Рекомендація: збільш години або скороти обсяг матеріалу.")

    result += [
        f"\\nДЕННИЙ ПЛАН:",
        f"  Тем на день: {topics_per_day:.1f}",
        f"  25-хвилинних сесій (Помодоро): {study_sessions}",
        f"  Перерви: 5 хв після кожної сесії, 15–30 хв після 4 сесій",
        f"\\nРЕКОМЕНДАЦІЇ:",
        "  1. Починай зі складних тем — поки свіжа голова.",
        "  2. Використовуй активне повторення: тести, флеш-картки.",
        "  3. Залиш останній день на загальне повторення.",
        "  4. Спи мінімум 7 годин — сон закріплює знання.",
    ]

    if days_available >= 7:
        result.append(f"\\nПРИКЛАД РОЗПОДІЛУ (перші {min(days_available, 7)} днів):")
        covered = 0
        per_day = max(1, round(topics_per_day))
        for day in range(1, min(days_available, 7) + 1):
            if covered >= topics_count:
                break
            end = min(covered + per_day, topics_count)
            result.append(f"  День {day}: теми {covered + 1}–{end}")
            covered = end

    return "\\n".join(result)

def run_studymate_session():
    """
    Інтерактивна сесія зі StudyMate.
    Пам'ять реалізована через список messages — повна історія передається
    в agent.invoke на кожному кроці.
    """
    print("\\n" + "=" * 60)
    print("📚 StudyMate — освітній AI-асистент")
    print("=" * 60)
    print("Команди: 'exit' — завершити, '/reset' — скинути контекст")
    print("-" * 60)

    messages = []

    while True:
        try:
            user_input = input("\\n👤 Ви: ").strip()
            if not user_input:
                continue

            if user_input.lower() in ("exit", "вихід", "/exit", "quit"):
                print("\\n👋 Дякую за використання StudyMate. Успіхів у навчанні!")
                break

            if user_input.lower() in ("/reset", "reset"):
                messages = []
                print("🔄 Контекст скинуто. Починаємо нову сесію.")
                continue

            messages.append({"role": "user", "content": user_input})

            print("\\n🤔 StudyMate думає...")
            result_state = agent.invoke({"messages": messages})
            messages = result_state["messages"]

            last_message = messages[-1]
            answer = (
                last_message.content
                if hasattr(last_message, "content")
                else last_message.get("content", "")
            )

            print("\\n🤖 StudyMate:")
            print(answer)

        except KeyboardInterrupt:
            print("\\n\\n👋 Сесію перервано. До побачення!")
            break
        except Exception as e:
            print(f"\\n❌ Помилка під час обробки запиту: {e}")
            print("Спробуй переформулювати запит.")

run_studymate_session()
