## Завдання 1. Персона плюс тональність (50 балів)

З коротких повідомлень витягнути персону і визначити тональність висловлювання
щодо неї. Формат відповіді строго:

`{"person":"<повне ім'я з тексту>","tone":"позитивна|нейтральна|негативна"}`

| Текст | Персона | Очікувана тональність |
|---|---|---|
| «Оксана Дрозд натхненно провела демо, команда аплодувала стоячи». | Оксана Дрозд | позитивна |
| «Керівник відділу Андрій Король грубо порушив інструкції, через що реліз зірвано». | Андрій Король | негативна |
| «Роман Бондаренко надіслав звіт о 14:00 і підтвердив графік зустрічей». | Роман Бондаренко | нейтральна |
| «Сьогодні Ілля Ткачук блискуче оптимізував код і заощадив 30% бюджету». | Ілля Ткачук | позитивна |
| «Марко Савченко ігнорує повідомлення й затримує погодження, це неприйнятно». | Марко Савченко | негативна |

Критерії прийняття: тільки JSON з рівно двома ключами, без коментарів і
markdown; `tone` лише з множини трьох класів; ім'я відтворене точно як у
тексті, без титулів і уточнень; для всіх 5 текстів відповідь парситься
через `json.loads()`.

Розбалка: формат JSON 20, коректність `person` 15, коректність `tone` 15.

## Завдання 2. Тріаж відгуків, продукт плюс пріоритет (25 балів)

Тріаж, це швидка класифікація і пріоритезація вхідних сигналів (відгуки,
баг-репорти, звернення в підтримку). Формат відповіді строго:

`{"product":"Atlas|Core|Desk","priority":"високий|середній|низький"}`

| Текст | Продукт | Пріоритет |
|---|---|---|
| «Квитанції не завантажуються в Atlas Pro з мобільного, фінвідділ стоїть». | Atlas | високий |
| «Після оновлення 3.1 у Core графіки будуються на 2 секунди довше, але працюють стабільно». | Core | середній |
| «Автовідповідь у Desk на свята, nice-to-have, допоможе трохи зменшити навантаження на операторів». | Desk | низький |
| «Core падає під час імпорту CSV >100 тис. рядків, роботу заблоковано». | Core | високий |
| «Atlas показує старі курси валют, поки що оновлюємо вручну». | Atlas | високий |

Підказки з умови: заборонити будь-який текст поза JSON, жорстко перелічити
допустимі значення, просити обирати домінантний пріоритет, якщо сигналів
кілька. Окремо перевіряється нормалізація «Atlas Pro» у «Atlas».

Розбалка: формат JSON 10, `product` 7, `priority` 8.

## Завдання 3. Заголовок плюс категорія оголошення (25 балів)

Згенерувати короткий заголовок (не більше 8 слів) і класифікувати категорію.
Формат відповіді строго:

`{"title":"<до 8 слів>","category":"реліз|інцидент|рекомендація"}`

| Текст | Категорія | Приклад бажаного заголовка |
|---|---|---|
| «Вийшла версія 2.0 з офлайн-режимом і новим дизайном». | реліз | «Реліз 2.0: офлайн і новий дизайн» |
| «У частини користувачів не відкривається профіль після апдейту; працюємо над виправленням». | інцидент | «Проблеми з профілем після оновлення» |
| «Збираємо відгуки про новий модуль аналітики». | рекомендація | «Поділіться думкою про аналітику» |
| «На вихідних сервіс у режимі планового обслуговування». | інцидент | «Планове обслуговування у вихідні» |
| «Рекомендуємо вмикати двофакторну автентифікацію». | рекомендація | «Увімкніть двофакторну автентифікацію» |

Підказки з умови: вимагати ліміт слів у заголовку, за потреби заборонити
розділові знаки, не використовувати службові слова на кшталт «Оголошення:».

Розбалка: формат JSON 10, категорія 7, заголовок 8.

                api_key=os.getenv("OPENROUTER_API_KEY", "sk-or-v1..."))
MODEL = "openai/gpt-oss-120b"  # замінюйте за потреби

texts = [...]

PROMPT_STUDENT = """
# TODO: Перепишіть інструкцію так, щоб модель повертала ТІЛЬКИ JSON-об'єкт.
"""

for t in texts:
    resp = client.chat.completions.create(
        model=MODEL,
        messages=[
            {"role": "developer", "content": PROMPT_STUDENT.strip()},
            {"role": "user",
             "content": f"Проаналізуй текст і поверни ТІЛЬКИ JSON з ключами person та tone.\nТекст: <<<{t}>>>"},
        ],
        temperature=0
    )
    result = resp.choices[0].message.content
    json.loads(result)
    print(result)
