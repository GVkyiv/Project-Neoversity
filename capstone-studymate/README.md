# Capstone: StudyMate

AI-освітній асистент з математики (основне) та фізики (другорядне) для
школярів і студентів молодших курсів. Хімія свідомо виключена — немає
достатньої бази знань з економічної освіти, щоб перевіряти якість відповідей.

Побудований на принципі **«відповідає тільки на основі бази знань»** — прямий
паралель до реальних enterprise-кейсів в ERC (актуальний перелік і статуси —
[erc-work/context.md](../erc-work/context.md), список зростає).

## Робочий код перенесено в окремий репозиторій

Починаючи з фінального проєкту, робочий Streamlit-застосунок живе окремо від
цього навчального монорепо, у власній папці зі своїм git-репозиторієм:

`D:\Documents\Google Drive\AI Project\Study\StudyMate\`

Причина: фінальний проєкт здається окремо (GitHub-посилання лише на цей
продукт), а не як частина конспектів курсу. Дублювати код у двох місцях
означало б тримати дві копії в синхроні вручну — замість цього тут
залишається лише архітектурний опис і наскрізний зв'язок з ДЗ, а код,
`requirements.txt` і README для зовнішньої аудиторії — у `../StudyMate`.

## Архітектура (фінальний проєкт, короткий опис)

Три шари агентної логіки, навмисно на різних фреймворках, бо кожен показує
інший клас поведінки:

**Шар 1: швидкий tool-calling (нативний Gemini, `google-genai`).** Три
інструменти:
- `formula_search` — семантичний пошук по 19 математичних формулах у трьох
  кластерах тем (квадратні рівняння, прогресії, геометрія), поріг схожості
  0.75 — нижче цього агенту заборонено вигадувати формули. Поріг
  відкалібрований заміром 10.08.2026: перенесені з ДЗ8 0.55 у просторі
  Gemini пропускали 9 з 10 запитів без формули в довіднику (деталі й цифри
  в [final_project_review.md](final_project_review.md)).
- `study_planner` — детермінований розрахунок розподілу часу, без участі LLM.
- `unit_converter_physics` — детермінована конвертація фізичних одиниць.

**Шар 2: покрокове міркування (Agno + `ReasoningTools`, перенесено з ДЗ11).**
Окремий агент для багатоступеневих текстових задач (рух з двома ділянками
тощо): думає через `think` → `analyze`, UI показує кожен крок міркування
окремо, а не лише фінальну відповідь. Живий тест підтвердив задокументований
у [DECISIONS_LOG.md](../DECISIONS_LOG.md) ризик: інструмент `analyze` іноді
падає з помилкою валідації обов'язкового аргументу `title` (нестабільно, не
щоразу). UI не приховує це, а показує `st.warning` з назвою інструмента, що
впав — чесна демонстрація межі системи, а не бага, який треба замовчати.

**Шар 3: команда агентів (Agno `Team`, Researcher + Analyst, перенесено з ДЗ11).**
Researcher шукає в інтернеті (DuckDuckGo), Analyst аналізує і оформлює звіт.
UI-перемикач `share_member_interactions` дозволяє живцем показати
задокументовану в ДЗ11 різницю: з увімкненим параметром Analyst бачить
відповідь Researcher і може посилатись на конкретні джерела, без нього
отримує лише коротке завдання без фактів. Верифікації фактів між агентами
немає — інтерфейс явно попереджає про це під кожним звітом.

⚠️ Безкоштовний тариф Gemini API обмежений 15 запитами/хв на модель
`gemini-3.5-flash-lite` — команда з двох агентів легко впирається в цей
ліміт при частому тестуванні поспіль.

Детальний опис запуску, залежностей і повний код — у
`../StudyMate/README.md`.
