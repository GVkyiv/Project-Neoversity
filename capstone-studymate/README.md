# Capstone: StudyMate

AI-освітній асистент з математики (основне) та фізики (другорядне) для
школярів і студентів молодших курсів. Хімія свідомо виключена — немає
достатньої бази знань з економічної освіти, щоб перевіряти якість відповідей.

Побудований на принципі **«відповідає тільки на основі бази знань»** — прямий
паралель до реальних enterprise-кейсів в ERC (актуальний перелік і статуси —
`../erc-work/context.md`, список зростає).

## Архітектура (за станом на ДЗ10)

Мінімальний агент з двома інструментами:

- `formula_search` — семантичний пошук по 19 математичних формулах у трьох
  кластерах тем (квадратні рівняння, прогресії, геометрія), поріг схожості
  0.55 — нижче цього агенту заборонено вигадувати формули.
- `study_planner` — детермінований розрахунок розподілу часу, без участі LLM.

Використовує нативний OpenAI tool-calling (`client.chat.completions.create`).
UI: три вкладки (Chat / Formulas / Plan), sidebar з параметрами навчання,
явні `st.warning`-компоненти, що показують задокументований архітектурний
ризик: самооцінка слабких тем + холодний старт (порожня історія для нового
користувача) означає, що план спирається на неверифіковану самооцінку.
