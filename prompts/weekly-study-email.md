# Промпт: письма-напоминания по учёбе

Инструкция для облачной рутины, которая шлёт письма по учёбе. Рутина
читает файлы из **GitHub** (`GVkyiv/Project-Neoversity`, ветка `master`),
а не с локального диска: если статус обновлён локально и не запушен,
письмо покажет старые данные.

Переработано 04.09.2026. Что было не так в старой версии и что здесь
исправлено:

1. В письмо валился **весь** список тем из `backlog.md`, включая
   отложенные и те, что даже не начинались. Теперь в недельном письме
   только активные треки, полный список отдельным письмом раз в месяц.
2. Ссылки вели непонятно куда. Теперь у каждого пункта в первую очередь
   ссылка `obsidian://` на **локальный файл**, GitHub только запасным.
3. У курсов Anthropic Academy файла в репозитории нет, поэтому им нужна
   прямая ссылка на сайт курса, а не на репозиторий.
4. Треки шли последовательно, письмо выдавало один модуль. Теперь треков
   три и идут они параллельно, письмо выдаёт по одному пункту с каждого.

## Три письма

| Письмо | Когда | Что делает |
|---|---|---|
| Недельное | понедельник 10:00 | Что учим на этой неделе. Основное письмо |
| Напоминание | пятница 18:00 | Попросить обновить статусы |
| Обзор | 1 числа месяца, 10:00 | Полный список тем, включая очередь |

Все три это облачные рутины, управляются через скил `schedule` или на
странице https://claude.ai/code/routines. Время в cron задаётся в UTC,
поэтому 10:00 Киева летом это `0 7`.

## Письмо 1. Понедельник, что учим на этой неделе

### Откуда брать данные

**Блок Neoversity** (обязательный, всегда первым):

- `CALENDAR.md` — текущая дисциплина, даты начала и конца, статус
- `STATE.md` — на какой теме курс, что уже сдано
- `PROGRAM.md` — темы дисциплины, веса оцениваемых работ

**Активные треки** — `to-learn/backlog.md`, раздел «Активно сейчас».
Обрабатывать **только** треки из этого раздела. Раздел «В очереди» в
недельное письмо не попадает никогда.

Для треков с файлами модулей (Obsidian, OpenRouter):

1. Прочитать все файлы `to-learn/<track>-module-*.md`
2. Взять первый модуль, у которого `status` во frontmatter **не** равен
   `done`, при равенстве смотреть на меньший `queue`
3. Даты недели брать из поля `week` во frontmatter, не парсить из текста
4. Список занятий и их галочки брать из чеклиста в теле файла

Для трека Anthropic Academy (файлов модулей нет):

1. Прочитать таблицу курсов в `to-learn/backlog.md`, трек 3
2. Взять первую строку со статусом не `освоено`
3. Ссылку брать **из таблицы как есть**, не собирать адрес по названию
   курса: слаги там неочевидные

### Как оформлять ссылки (правило от 04.09.2026)

**Отдельных строк-ссылок в письме больше нет.** Слов «Открыть у себя»,
«Посмотреть на GitHub», «Пройти курс» быть не должно, как и самих
ссылок на GitHub. Ссылка вешается прямо на название того, что открывают,
через `<a href>`.

Что становится ссылкой:

| Текст в письме | Куда ведёт |
|---|---|
| Название модуля («Obsidian, модуль 1: база и гигиена vault») | файл модуля в Obsidian |
| Каждое название занятия («Занятие 1. Настройка vault...») | тот же файл, с переходом к заголовку этого занятия |
| Название курса Anthropic Academy | страница курса, адрес из таблицы `backlog.md` как есть |

**Как собрать ссылку на файл модуля:**

```
obsidian://open?vault=Project%20Neoversity&file=to-learn%2F<имя-файла-без-расширения>
```

Готовые ссылки этого вида уже лежат в `obsidian-plan.md` и
`openrouter-plan.md`, копировать оттуда дословно.

**Как собрать ссылку на конкретное занятие.** К той же ссылке дописать
`%23` и URL-кодированный заголовок занятия из тела файла модуля (в файле
это строка вида `## Занятие 1. Настройка vault под этот репозиторий`,
брать её целиком без решёток). Кодировать через python, не вручную:

```python
import urllib.parse
anchor = urllib.parse.quote("Занятие 1. Настройка vault под этот репозиторий", safe="")
```

Результат приклеивается к ссылке на файл:
`obsidian://open?vault=Project%20Neoversity&file=to-learn%2Fobsidian-module-1%23<anchor>`

Если по какой-то причине заголовок закодировать не удалось, ставить
обычную ссылку на файл модуля без якоря. Битую ссылку не отправлять
никогда.

### Типографика письма

`htmlBody` целиком обернуть в контейнер с базовым размером шрифта
**17px** и `line-height: 1.5`. Это примерно на 20% крупнее того, что
почтовый клиент ставит по умолчанию: письмо читается с телефона и мелкий
шрифт был неудобен. Заголовки блоков 21-22px, названия треков 19px.
Ссылки подчёркнутые, чтобы их было видно как ссылки.

Пример каркаса:

```html
<div style="font-size:17px; line-height:1.5; font-family:-apple-system,Segoe UI,Roboto,sans-serif;">
  ...
</div>
```

В поле `body` (простой текст) размер шрифта задать нельзя, поэтому туда
идёт тот же текст без разметки, а ссылки в нём выписываются полными
адресами в скобках после названия.

### Правила текста

- Язык письма русский
- Тире не использовать, вместо него дефис, запятая или двоеточие
  (общее правило репозитория из `AGENTS.md`)
- «Коротко, что осваиваем» это 2-3 пункта, каждый в одну строку, своими
  словами по содержанию модуля. Не копировать заголовки занятий дословно:
  занятия и так идут отдельной строкой ниже
- Если у трека все модули `done`, показать одну строку «трек закрыт
  <дата>» и не выдумывать следующий модуль
- Если модуль уже `in-progress`, так и написать, и показать, какие
  занятия отмечены, а какие нет
- Ничего не придумывать: чего нет в файлах, того нет в письме
- Никаких слов-обёрток вокруг ссылок («Открыть», «Смотреть», «Перейти»,
  «Ссылка»): кликают по самому названию модуля, занятия или курса

## Письмо 2. Пятница, напоминание обновить статусы

Короткое. Перечислить те же активные пункты, что были в понедельник, и
по каждому спросить, что сделано. Напомнить два способа ответить:

1. Через Claude Code в проекте `Project Neoversity`: сказать «обновил
   модуль N, занятия 1 и 2 сделал, третье нет, причина такая-то».
   Claude Code проставит галочки, поменяет `status`, запишет строку в
   «Журнал» и закоммитит
2. Руками в Obsidian, открыв файл кликом по названию занятия, потом
   `git push`

Обязательно напомнить про `git push`: без него следующее письмо покажет
старые данные, потому что рутина читает GitHub.

Ссылки и типографика те же, что в письме 1: базовый шрифт 17px, отдельных
строк-ссылок и упоминаний GitHub нет, кликают по названиям занятий.
