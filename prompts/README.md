# Prompts

Багаторазові промпти, що не прив'язані до одного ДЗ чи дисципліни, а
повторюються з курсу в курс. На відміну від [DECISIONS_LOG.md](../DECISIONS_LOG.md) (зафіксовані
висновки з фактично зробленого) це — робочі інструкції для конкретного типу
задачі.

## Файли

- **[scientific-article-review.md](scientific-article-review.md)** — розбір наукової статті (переклад
  частинами + рецензія за фіксованою структурою курсу). Завдання «Наукова
  публікація» повторюється майже в кожній дисципліні Neoversity.
  **Правило для ІІ-асистента: якщо я кажу щось на кшталт «розбери наукову
  статтю», «зроби рецензію на статтю», «завдання по науковій публікації» — і
  прикладаю текст/файл/посилання статті, застосовувати цей промпт як стандарт
  без перепитування формату**, якщо я явно не скажу інакше. Приклад
  завершеного результату за цим промптом:
  [tier2/ai-fundamentals/homework/scientific-review/](../tier2/ai-fundamentals/homework/scientific-review/README.md) (30.07.2026), а також
  [tier1/human-computer-interaction-design/homework/scientific_review_1/](../tier1/human-computer-interaction-design/homework/scientific_review_1/README.md) і
  [scientific_review_2/](../tier1/human-computer-interaction-design/homework/scientific_review_2/README.md).
- **[python-tutor.md](python-tutor.md)** — режим викладача Python для новачка, покроково за
  програмою курсу [«Робота з Python»](../tier1/python-programming/PYTHON.md) (Tier 1, вже пройдено). Може знадобитись
  як шаблон для наступних технічних курсів, де я теж починаю з нуля.
- **[vibe-coding-refiner.md](vibe-coding-refiner.md)** — Vibe Prompt Refiner: перетворення сирого
  запиту в структурований JSON-промпт (задача, вимоги, ризики, план ітерацій).
  Загальноприкладний інструмент, не специфічний для Neoversity.
- **Листи-нагадування по навчанню** — три окремі хмарні рутини, кожна свій
  файл, спільні правила винесені окремо. Розбито 14.09.2026 з одного файлу
  `weekly-study-email.md`, щоб кожен лист був окремою сутністю і новий лист
  можна було додати, не чіпаючи інші. Рутини живуть у хмарі, промпти тут,
  щоб бути під версійним контролем і правитись разом з планами в
  [to-learn/](../to-learn/backlog.md):
  - **[email-common.md](email-common.md)** — спільна база: звідки рутина
    читає дані з репозиторію, оформлення посилань, типографіка листа,
    правила тексту
  - **[email-weekly.md](email-weekly.md)** — тижневий лист (понеділок 10:00):
    що учимо цього тижня по трьох активних треках, плюс блок «хвости»
    незакритого з минулих тижнів
  - **[email-friday-reminder.md](email-friday-reminder.md)** — нагадування
    оновити статуси (п'ятниця 18:00)
  - **[email-monthly-overview.md](email-monthly-overview.md)** — повний огляд
    усіх тем, включно з чергою (1 число місяця 10:00)
- **[ai-video-review.md](ai-video-review.md)** — розбір навчального/новинного відео про AI з
  YouTube за транскриптом: резюме, факт-чек, звірка з актуальними трендами AI,
  зв'язок з навчанням і з ERC, критичний висновок «застосовувати чи ні». Для
  окремої гілки [ai-trends/](../ai-trends/README.md), не прив'язаної до
  конкретної дисципліни. **Правило для ІІ-асистента: якщо я вставляю
  транскрипт відео з YouTube — застосовувати цей промпт як стандарт без
  перепитування формату.**
