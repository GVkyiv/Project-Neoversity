# Лист 2: п'ятниця, нагадування оновити статуси

Хмарна рутина, надсилається щоп'ятниці о 18:00 Києва. Спільні правила
(звідки читати дані, оформлення посилань, типографіка, правила тексту)
винесені в [email-common.md](email-common.md), тут тільки те, що
специфічне для цього листа. Виділено 14.09.2026 з єдиного файлу
`weekly-study-email.md`.

## Зміст

Короткий. Перерахувати ті самі активні пункти, що були в понеділковому
листі ([email-weekly.md](email-weekly.md)), і по кожному запитати, що
зроблено. Нагадати два способи відповісти:

1. Через Claude Code в проєкті `Project Neoversity`: сказати «оновив
   модуль N, заняття 1 і 2 зробив, третє ні, причина така-то».
   Claude Code проставить галочки, поміняє `status`, запише рядок у
   «Журнал» і закомітить
2. Руками в Obsidian, відкривши файл кліком по назві заняття, потім
   `git push`

Обов'язково нагадати про `git push`: без нього наступний лист покаже
старі дані, бо рутина читає GitHub, не локальний диск.

Посилання і типографіка ті самі, що в листі 1: [email-common.md](email-common.md).
