# Гермес десктоп (Hermes Agent, Nous Research)

## Джерело

YouTube, канал "Продсовет" (дядя Даня). Назва відео не вказана явно у
наданому транскрипті, тема: огляд десктопного застосунку Hermes Agent
(в транскрипті "Гермес"), посилання на відео не надано, лише текстовий
транскрипт. Дата перегляду: 2026-08-09.

## Резюме

Hermes Agent (Nous Research) відкритий, модель-агностичний агентний
харнес: одне ядро, кілька поверхонь (CLI, TUI, нативний Electron-десктоп,
веб-дашборд, ACP-сервер для IDE). Десктоп це не окремий продукт, а
графічна обгортка над тим самим CLI-агентом, сесії й налаштування спільні.

Ключові фічі з відео: підключення кількох провайдерів одночасно
(основний, наприклад ChatGPT-підписка $20/міс, плюс дешевший другий
провайдер для рутинних задач через Auxiliary Models), профілі як
ізольовані "цифрові співробітники" з власним промптом/провайдером/
моделлю/пам'яттю, gateway на месенджери (в демо Telegram), скіли (кастомні
й вбудовані), cron-задачі, drag-and-drop файлів у контекст, розділ
"Артефакти" для візуальних результатів сесій. Демо: створення профілю
"ПА бізнес", кастомний скіл читання Google Таблиці через OAuth, cron на
перевірку нових заявок з нотифікацією в Telegram.

## Факт-чек

- **Hermes Agent це реальний opensource-проєкт Nous Research, десктоп
  доданий у релізі v0.16.0 "The Surface Release" (5 червня 2026)** —
  підтверджено офіційною документацією.
- **Десктоп це обгортка над тим самим CLI-агентом, спільні сесії й
  налаштування** — підтверджено.
- **"Обігнав по популярності" конкурента (в транскрипті спотворено до
  "Пенклопа", йдеться про OpenClaw)** — невірно/перебільшення. На момент
  перевірки OpenClaw лідирує за зірками GitHub (~375K проти ~220K у
  Hermes). Hermes дійсно зростає швидше за конкурентів, але
  "обігнав по популярності" не відповідає дійсності.
- **Профілі, gateway на месенджери (20+ платформ), Auxiliary Models
  (дешевший провайдер на рутинні задачі), скіли, що можуть керувати
  іншими харнессами як субагентами (Claude Code, Codex, OpenCode)** —
  підтверджено офіційною документацією.
- **Порівняння з Claude Code (незалежна перевірка, не з відео):** це різні
  категорії інструментів. На чистому кодингу/рефакторингу Claude Code
  (особливо на Opus) залишається сильнішим або не гіршим за незалежними
  бенчмарками (SWE-bench Verified 88.6% у Opus 4.8; у прямому тесті на
  8 багфіксах Claude Code закрив 7/8, Hermes 6/8). Перевага Hermes не в
  якості коду, а в охопленні задач поза одним репозиторієм
  (автоматизація, месенджери, "цифрові співробітники"). Теза відео
  "забуваємо про ці клодекси" не підтверджується об'єктивним порівнянням.
- **Підключення Claude-підписки (Pro/Max) до Hermes замість Anthropic
  API** — з квітня 2026 технічно заблоковано. Anthropic офіційно
  забороняє використання OAuth-токена підписки (Free/Pro/Max) у
  сторонніх інструментах, з 04.04.2026 додана серверна валідація, що
  відхиляє такі запити. Навіть коли це раніше частково працювало, це
  стосувалося лише тарифу Max і лише докупленого "extra usage", а не
  базового ліміту підписки. Офіційно підтримуваний шлях для Claude
  всередині Hermes це API-ключ (оплата за токени), не підписка.
  У відео автор саме тому підключав ChatGPT-підписку, а не Claude,
  ця важлива деталь у самому відео не проговорена.

## Актуальність

Перевірено веб-пошуком 2026-08-09. Продукт активно розвивається,
інформація з відео відповідає стану на момент запису (десктоп додано
у червні 2026). Динамічні дані (зірки на GitHub, гонка з OpenClaw)
змінюються швидко, конкретну цифру "обігнав/не обігнав" варто
перевіряти повторно на момент прийняття рішення.

## Зв'язок з навчанням

Пряме перетинання з Tier 2, AI Fundamentals, темою 11 (агенти на Agno):
скіли, субагенти, пам'ять, роутинг між дешевою і дорогою моделлю це ті
самі архітектурні патерни, які вже розбирались у ДЗ11 (Agno,
`share_member_interactions`, `ReasoningTools`). Корисно як третя точка
порівняння фреймворків поруч із LangChain/Agno з того ДЗ, якщо
знадобиться для майбутнього завдання.

## Зв'язок з ERC

Пряме практичне застосування до двох пунктів з `erc-work/context.md`:

1. **IT support-бот** — профіль-агент із власним системним промптом,
   доступом до робочого контексту через Telegram gateway.
2. **Інструмент автоматизації аналізу даних** — скіл читання Google
   Таблиці, порівняння state, нотифікація в Telegram при новому записі.
   Це переноситься на внутрішні процеси ERC (заявки/тікети замість
   клієнтських лідів).

Не додаю це як новий пункт до `erc-work/context.md` без окремого
підтвердження, але як конкретний технічний підхід до вже існуючих
пунктів 1 і 2 це підходить добре.

## Висновок

Відео технічно достовірне майже повністю, крім одного помітного
перебільшення ("обігнав по популярності" OpenClaw) і одного важливого
замовчування (Claude-підписку до Hermes підключити не можна, це
заборонено Anthropic з квітня 2026, потрібен або окремий API-ключ, або
ChatGPT-підписка). Порівняння з Claude Code некоректне на рівні "що
краще" — це інструменти для різних задач, на чистому кодингу Claude Code
не поступається.

**Дія:** варто перевірити Hermes практично, для авторизації через
підписку (а не через дорожчий API за токенами) знадобиться підписка на
ChatGPT, оскільки підписку Claude підключити так не можна. Пілотну
перевірку має сенс проводити на одному з реальних процесів ERC
(наприклад нотифікація про нові заявки/тікети через Telegram gateway) як
обмежений експеримент, не як заміну поточної інфраструктури.
