# JavaScript Fundamentals: From Basics to Advanced Concepts

Tier 1. Статус: **пройдено**.

У джерельній таблиці Neoversity було дві версії курсу (v1 і v2.0) з різним
переліком модулів — підтверджено: пройдено **v2.0**.

## Зроблено (у `homework/`)

ДЗ у форматі GOIT-шаблонів (`goit-js-hw-0N`), кожен — окремий мінісайт з
`index.html` + `js/task-N.js`:

- [goit-js-hw-01](homework/goit-js-hw-01/goit-js-hw-01_functions-template-strings.md) — функції, шаблонні рядки, базова арифметика
  (`makeTransaction`, `getShippingMessage`, `getElementWidth`)
- [goit-js-hw-02](homework/goit-js-hw-02/goit-js-hw-02_conditionals-validation.md) — умовні конструкції, валідація вводу (перевірка балансу,
  довжини повідомлення, спам-фільтр, вартість доставки за країною)
- [goit-js-hw-03](homework/goit-js-hw-03/goit-js-hw-03_strings-arrays.md) — робота з рядками і масивами (`slugify`, об'єднання
  масивів з обмеженням довжини, фільтрація масиву)
- [goit-js-hw-04](homework/goit-js-hw-04/goit-js-hw-04_arrays-of-objects.md) — робота з масивами об'єктів (перевірка місткості
  контейнера, середнє значення калорій за днями)
- [goit-js-hw-05](homework/goit-js-hw-05/goit-js-hw-05_map-filter-reduce.md) — методи масивів вищого порядку (`map`, `filter`, `sort`,
  `reduce`) на масиві користувачів: імена, друзі, сортування, сума балансу за
  статтю
- [goit-js-hw-06](homework/goit-js-hw-06/goit-js-hw-06_oop-classes-private-fields.md) — ООП: об'єкти з методами, класи з приватними полями
  (`#items`), інкапсуляція (`Storage`, `StringBuilder`)
- [goit-js-hw-07](homework/goit-js-hw-07/goit-js-hw-07_dom.md) — робота з DOM: генерація/видалення елементів, випадкові
  кольори, 6 окремих задач з власними html-сторінками
- [goit-js-hw-08](homework/goit-js-hw-08/goit-js-hw-08_gallery-modal.md) — галерея зображень з модальним вікном (клік по
  превʼю → показ повного зображення)
- [goit-markup-hw-01](homework/goit-markup-hw-01/goit-markup-hw-01_planet-fatness-landing.md) — верстка (HTML/CSS), лендінг "Planet Fatness"
- [java_test_todo_app/](homework/java_test_todo_app/java_test_todo_app_classes-inheritance.md) — окремий навчальний проєкт (був під git),
  to-do застосунок: класи `User`/`Admin` з успадкуванням, приватні поля,
  геттери/сеттери, статичні поля (`Admin.role`)
