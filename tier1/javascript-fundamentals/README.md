# JavaScript Fundamentals: From Basics to Advanced Concepts

Tier 1. Статус: **пройдено**.

У джерельній таблиці Neoversity було дві версії курсу (v1 і v2.0) з різним
переліком модулів — підтверджено: пройдено **v2.0**.

## Зроблено (у `homework/`)

ДЗ у форматі GOIT-шаблонів (`goit-js-hw-0N`), кожен — окремий мінісайт з
`index.html` + `js/task-N.js`:

- [goit-js-hw-01](homework/goit-js-hw-01/README.md) — функції, шаблонні рядки, базова арифметика
  (`makeTransaction`, `getShippingMessage`, `getElementWidth`)
- [goit-js-hw-02](homework/goit-js-hw-02/README.md) — умовні конструкції, валідація вводу (перевірка балансу,
  довжини повідомлення, спам-фільтр, вартість доставки за країною)
- [goit-js-hw-03](homework/goit-js-hw-03/README.md) — робота з рядками і масивами (`slugify`, об'єднання
  масивів з обмеженням довжини, фільтрація масиву)
- [goit-js-hw-04](homework/goit-js-hw-04/README.md) — робота з масивами об'єктів (перевірка місткості
  контейнера, середнє значення калорій за днями)
- [goit-js-hw-05](homework/goit-js-hw-05/README.md) — методи масивів вищого порядку (`map`, `filter`, `sort`,
  `reduce`) на масиві користувачів: імена, друзі, сортування, сума балансу за
  статтю
- [goit-js-hw-06](homework/goit-js-hw-06/README.md) — ООП: об'єкти з методами, класи з приватними полями
  (`#items`), інкапсуляція (`Storage`, `StringBuilder`)
- [goit-js-hw-07](homework/goit-js-hw-07/README.md) — робота з DOM: генерація/видалення елементів, випадкові
  кольори, 6 окремих задач з власними html-сторінками
- [goit-js-hw-08](homework/goit-js-hw-08/README.md) — галерея зображень з модальним вікном (клік по
  превʼю → показ повного зображення)
- [goit-markup-hw-01](homework/goit-markup-hw-01/README.md) — верстка (HTML/CSS), лендінг "Planet Fatness"
- [java_test_todo_app/](homework/java_test_todo_app/README.md) — окремий навчальний проєкт (був під git),
  to-do застосунок: класи `User`/`Admin` з успадкуванням, приватні поля,
  геттери/сеттери, статичні поля (`Admin.role`)
