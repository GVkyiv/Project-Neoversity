# Human-Computer Interaction and Design: theory and techniques

Tier 1. Статус: **пройдено**.

Наскрізний навчальний проєкт курсу: **Personal Finance Hub** («Всі фінанси в
одному місці») — фінтех-дашборд, що агрегує рахунки, активи (крипто, ETF,
акції) і цілі накопичення в одному місці, з синхронізацією через API банків
(Монобанк тощо). Макети робились у Figma.

## Примітка

`.fig` і `.jam` — бінарні файли Figma/FigJam, ІІ-асистент не може прочитати
їх вміст напряму, лише каталогізувати. Google Docs-файли (`.gdoc`) з вихідної
теки не копіювалися — це файли-ярлики на онлайн-документ, а не сам вміст;
реальний контент взято з відповідних `.docx`/`.pdf`.
