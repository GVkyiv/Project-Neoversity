## Не вистачає

Конспекти лекцій. Артефакти збірки (PyInstaller `build/`, `dist/`, готові
`.exe`-інсталятори) з вихідних папок свідомо не завантажені — це не код, а
згенеровані бінарники; за потреби зібрати заново з джерела.
