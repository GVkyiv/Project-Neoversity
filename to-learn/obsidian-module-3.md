## Зачем этот модуль

Базы из модуля 2 работают только пока frontmatter проставлен правильно.
Если новый файл создаётся руками, рано или поздно поле забудется и
таблица начнёт врать. Шаблоны убирают эту возможность.

В этом модуле ставятся два плагина: **Templater** и **QuickAdd**. Раньше
их ставить не нужно было, и это принцип, а не случайность: плагин
ставится в тот день, когда до него дошла очередь.

## Занятие 8. Шаблоны: core Templates, затем Templater

**Теория (15 мин):** сначала core-плагин Templates, он уже включён.
Потом почему его не хватает и что добавляет Templater.

**Практика (45 мин):**

1. Создать папку `_templates/`, указать её в настройках Templates
2. Сделать шаблон нового ДЗ: frontmatter точно по схеме из `README.md`
3. Установить **Templater**
4. Переделать шаблон на Templater: дата подставляется сама, поле
   `discipline` подтягивается из имени папки
5. Сделать второй шаблон, разбор видео, по структуре существующих файлов
   в `ai-trends/reviews/`

**Проверка:** новый файл ДЗ создаётся из шаблона с уже заполненным
корректным frontmatter, дописывать руками нечего.

## Занятие 9. QuickAdd: захват без трения

**Теория (10 мин):** документация QuickAdd, типы действий Template и
Capture.

**Практика (50 мин):**

1. Установить **QuickAdd**
2. Команда «Новое ДЗ»: спрашивает дисциплину, создаёт файл из шаблона
   занятия 8 в правильной папке
3. Команда «Новый разбор видео» в `ai-trends/reviews/`
4. Capture: добавить строку в `to-learn/backlog.md` из любого места
   vault, не открывая файл
5. Повесить обе команды на горячие клавиши

**Проверка:** новый пункт в backlog добавляется за два нажатия из любой
заметки.
