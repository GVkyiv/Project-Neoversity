### Трек 1. Obsidian

- Статус: в процессе
- Что это: приложение для заметок на локальных markdown-файлах со
  связями между заметками. Установлен, репозиторий открыт как vault,
  стоят Dataview, Omnisearch, Notebook Navigator
- Зачем: превратить этот репозиторий в рабочую базу знаний, где Claude
  Code пишет файлы, а Obsidian даёт навигацию и дашборды
- **План: [obsidian-plan.md](obsidian-plan.md)**, 4 модуля, 13 занятий по
  часу, 31.08-27.09.2026
- Модули: [1. База и гигиена vault](obsidian-module-1.md) (31.08-06.09) ·
  [2. Vault как база данных](obsidian-module-2.md) (07.09-13.09) ·
  [3. Ввод и шаблоны](obsidian-module-3.md) (14.09-20.09) ·
  [4. Сшивка с Claude Code](obsidian-module-4.md) (21.09-27.09)
- Заметки: платный курс obsidian.second-brain.ru сознательно не берём,
  причины в плане

### Трек 2. OpenRouter.ai

- Статус: в процессе (модуль 1, занятие 1 закрыто 04.09.2026)
- Что это: единый API-шлюз и маркетплейс, один ключ и один формат запроса
  к 500+ моделям от 80+ провайдеров
- Зачем: обоснованный выбор модели под задачу с цифрами по цене и
  качеству. Совпадает с темой 3 текущего курса и закрывает открытую
  проблему ERC с саммаризацией длинных совещаний
- **План: [openrouter-plan.md](openrouter-plan.md)**, 4 модуля, 12
  занятий, 31.08-27.09.2026, **параллельно с Obsidian**
- Модули: [1. Что это, деньги и первое сравнение](openrouter-module-1.md)
  (31.08-06.09) · [2. API и перенос кода курса](openrouter-module-2.md)
  (07.09-13.09) ·
  [3. Роутинг, надёжность, структурированный вывод](openrouter-module-3.md)
  (14.09-20.09) ·
  [4. Решение для реальной задачи ERC](openrouter-module-4.md)
  (21.09-27.09)
- Заметки: OpenRouter не дешевле прямого доступа к той же модели, при
  пополнении картой комиссия 5,5% плюс минимум 0,80 USD. Платишь за выбор
  и сравнимость, а не за экономию

### Hermes Agent

- Статус: отложено (напомнить 03.11.2026)
- Что это: открытый, модель-агностичный агентный харнес (Nous Research),
  десктоп-версия с релиза v0.16.0 (июнь 2026). Не аналог Claude Code, а
  инструмент для задач за пределами одного репозитория: месенджер-gateway,
  профили-«цифровые сотрудники», cron-задачи. Разобрано с факт-чеком в
  [ai-trends/reviews/2026-08-09_hermes-desktop.md](../ai-trends/reviews/2026-08-09_hermes-desktop.md)
- Зачем: пилотная автоматизация процессов ERC вне кодинга (см.
  [erc-work/context.md](../erc-work/context.md), пункты 1 и 2 в разборе)
- Отложено 29.08.2026: авторизация требует подписку ChatGPT, не Claude.
  Вернуться 03.11.2026, когда снова будет актуальна подписка ChatGPT
- План действий (из вывода разбора, раздел «Дія»):
  1. Установить Hermes Agent
  2. Для авторизации через подписку нужна подписка **ChatGPT**, не Claude:
     с 04.2026 Anthropic блокирует OAuth-токен Claude-подписки в сторонних
     инструментах; альтернатива это Claude API-ключ (платно за токены)
  3. Провести ограниченный пилот на одном реальном процессе ERC (например
     cron-нотификация о новых заявках в Telegram через gateway), не как
     замену текущей инфраструктуры
  4. Не сравнивать с Claude Code как «что лучше»: для чистого кодинга
     Claude Code сильнее по независимым бенчмаркам (SWE-bench, прямой тест
     7/8 против 6/8), у Hermes другое назначение
