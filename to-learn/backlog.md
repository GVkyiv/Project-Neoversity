### Obsidian
- Статус: не начато
- Что это: приложение для заметок на основе локальных markdown-файлов со связями между заметками (граф знаний)
- Зачем: организация заметок/базы знаний; этот репозиторий (Project Neoversity) уже настроен как Obsidian vault (`.obsidian/`, frontmatter в ДЗ под Dataview — см. README.md), то есть база для практики уже готова
- План действий:
  1. Установить Obsidian (obsidian.md), открыть как vault папку `Project Neoversity` (конфиг уже есть)
  2. Установить плагин Dataview, построить таблицу статусов ДЗ по полям `tier`/`discipline`/`status` из frontmatter — README.md проекта уже описывает этот формат, но таблица ещё не построена
  3. Освоить `[[wikilinks]]` и панель backlinks на паре существующих заметок (например, связать `DECISIONS_LOG.md` и `STATE.md`)
  4. Посмотреть Graph view для всего vault — оценить, насколько связи между заметками уже читаемы
  5. Опционально: плагин Templates для автоматической вставки frontmatter-блока в новые ДЗ вместо ручного копирования
- Заметки: —

### OpenRouter.ai
- Статус: не начато
- Что это: сайт-маркетплейс/единый API для доступа к разным LLM (GPT, Claude, Llama, Gemini и др.) через один ключ
- Зачем: сравнение моделей, доступ к моделям без отдельных подписок
- План действий:
  1. Зарегистрироваться на openrouter.ai, получить API-ключ
  2. Пополнить баланс на небольшую тестовую сумму ($5-10)
  3. В веб-плейграунде сравнить 2-3 модели (например Claude, GPT, Gemini) на одной и той же практической задаче — оценить разницу в цене и качестве на конкретном примере, не абстрактно
  4. Опционально: вызвать API из простого скрипта — сравнить с прямым вызовом Claude API из курса Anthropic Academy «Building with the Claude API», чтобы увидеть разницу между унифицированным и нативным API на практике
- Заметки: —

### Hermes Agent
- Статус: не начато
- Что это: открытый, модель-агностичный агентный харнес (Nous Research), десктоп-версия с релиза v0.16.0 (июнь 2026). Не аналог Claude Code, а инструмент для задач за пределами одного репозитория — месенджер-gateway, профили-«цифровые сотрудники», cron-задачи. Разобрано с факт-чеком в `ai-trends/reviews/2026-08-09_hermes-desktop.md`
- Зачем: пилотная автоматизация процессов ERC вне кодинга (см. связь с `erc-work/context.md`, пункты 1 и 2 в разборе)
- План действий (из вывода разбора, раздел «Дія»):
  1. Установить Hermes Agent
  2. Для авторизации через подписку нужна подписка **ChatGPT**, не Claude — с 04.2026 Anthropic блокирует OAuth-токен Claude-подписки в сторонних инструментах; альтернатива — Claude API-ключ (платно за токены)
  3. Провести ограниченный пилот на одном реальном процессе ERC (например cron-нотификация о новых заявках в Telegram через gateway), не как замену текущей инфраструктуры
  4. Не сравнивать с Claude Code как «что лучше» — для чистого кодинга Claude Code сильнее по независимым бенчмаркам (SWE-bench, прямой тест 7/8 против 6/8), у Hermes другое назначение
- Заметки: —
