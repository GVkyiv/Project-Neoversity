# Applied Computer Science: Capstone project

Tier 3. Фінальний дипломний проєкт програми — 259 год за таблицею, включно з
щотижневими звітами (7 тижнів), передзахистом і захистом. Вага диплому — 100%
від Summative assignment.

Ймовірно, це саме той рівень, де Capstone StudyMate (див.
`capstone-studymate/`) буде здаватись у фінальному вигляді — перевірити це
припущення, коли дійде до Tier 3.
